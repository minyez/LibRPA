How to Cite
===========

If you use LibRPA in your work, please consider citing the software paper and
the relevant methodological papers for the features you use.

The software paper:

- R. Shi, M.-Y. Zhang, P. Lin, L. He, and X. Ren,
  LibRPA: A software package for low-scaling first-principles calculations of random phase approximation electron correlation energy based on numerical atomic orbitals,
  *Comput. Phys. Commun.* **309**, `109496 (2025) <https://doi.org/10.1016/j.cpc.2024.109496>`_.
