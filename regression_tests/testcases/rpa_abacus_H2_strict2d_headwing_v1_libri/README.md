# ABACUS reader-v1 strict-2D RPA head/wing

This compact H2 data set is generated by the ABACUS
`61_LIBRPA_2D_READER_V1` producer configuration with a 2s1p orbital basis.
It has regular auxiliary-basis channels in addition to the Coulomb head, so
the strict-2D analytic head/wing route is exercised rather than only checked
for file presence.

The case requires `librpa_2d_coulomb_head.txt` and runs the reader-v1,
full-2D-Ewald, q-averaged RPA path. It intentionally uses the ABACUS velocity
matrix (`use_pyatb = f`) to keep the smoke test compact.
