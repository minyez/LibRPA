# H2 Delta-ST reader-v1 RPA regression

This is a compact ABACUS-to-LibRPA `sternheimer_rpa` integration regression.
The archive contains a real H2 Gamma response generated by ABACUS commit
`f54846b798ed8848f0f425abdd9f69723261a249`, using reader-v1 names and one
imaginary-frequency point.  It exercises the current `v1_Cs_data_`,
`v1_coulomb_full_iq_`, and `v1_sternheimer_chi0_iq_` readers through the
Delta-Sternheimer RPA energy path.

The molecular fixture deliberately sets `replace_w_head = false`: an isolated
molecule has no periodic analytic head/wing moment input.  This is an
interface regression, not a physical-convergence reference.  The archived
response is 322840 bytes and its expected energy is
`-5.093252455998e-05 Ha`.

On `df_iopcas_ghj`, one MPI rank with the oneAPI 2024.2 runtime completed this
case in less than one minute.  The package uses no legacy symmetry sidecars.
